# AppInstall v1.8.0 — Updates & Discover

AppInstall v1.8.0 introduces reviewed application updates, richer Discover browsing, and a redesigned Application Details page. This release contains changes merged through PRs #78–#87.

## What's new

- **Updates manager:** discover available changes by package source, review an update before applying it, and see clear available, current, unsupported, and error states.
- **Flatpak updates:** opt-in individual updates with source/target verification and confirmation. Dependency changes aren't silently approved.
- **DEB/RPM updates:** explicitly reviewed APT/DNF transactions for AppInstall-owned Debian/Fedora Distrobox packages. Foreign or imported packages remain manual; no unreviewed host-wide upgrades.
- **AppImage updates:** optional supported zsync-based updates with staging, validation, replacement, and recovery. Many AppImages still require manual updates; the external updater is optional.
- **Discover Apps:** source-aware metadata, best-effort verified icons, actual category filtering, and a Flathub-backed Featured shelf.
- **Application Details:** responsive, centered layout with description, developer, version, license, source, package identity, optional official website, and familiar reviewed Install actions.
- **Portable AppInstall self-updates:** non-native Linux systems with the portable runtime can explicitly update a user-source installation from a published stable archive verified against its SHA256SUMS. Native installs continue through their native package path.

| Fedora 44 | `appinstall-1.8.0-1.noarch.rpm` |
| Other Linux distributions with portable prerequisites | `appinstall-1.8.0-portable.tar.gz` |

All four packages are accompanied by `SHA256SUMS`. Download the exact archive matching your installation method and verify the SHA-256 checksum before installation. The portable archive is source code, **not** a universal precompiled Linux executable. It requires a suitable Python 3, Bash, Qt/PySide6 desktop runtime and optional source-specific tools; some distributions and desktop environments support only the CLI.

Native install/upgrade instructions: [AppInstall README](https://github.com/aboodmohd/-AppInstall#install-appinstall). For a portable installation, verify and extract the source bundle, then run `bash install-user.sh` as an ordinary non-root user. Existing pre-v1.8 portable installs may need to bootstrap this release manually once to obtain the portable in-app updater.

## Security and compatibility

Source checksums validate integrity, not an independent digital signature of the publisher. Distrobox containers are **not** security sandboxes. Package provenance, runtime dependencies, desktop integration and update support vary by Linux family. Not all apps supply icons, licenses, or machine-readable update metadata; missing information is shown as unavailable. The new update flows require explicit confirmation and do not automatically update all installed applications.

See [known limitations](https://github.com/aboodmohd/-AppInstall/blob/main/KNOWN_LIMITATIONS.md) and [cross-distro update support](https://github.com/aboodmohd/-AppInstall/blob/main/docs/CROSS_DISTRO_UPDATE_SUPPORT.md).
